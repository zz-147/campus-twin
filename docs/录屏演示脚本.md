# 录屏演示脚本（3 分钟主版 + 5 分钟加长版）

> 目标：一段能直接发给面试官 / 放简历链接的演示视频。
> 原则：**先给结论、再演真实、每 30 秒一个信息点**；不念 UI，讲"为什么"。

---

## 一、录制前准备（10 分钟）

### 1) 环境
- 关闭无关窗口（微信、浏览器其它标签），桌面清理干净
- 屏幕分辨率 1920×1080（或 2560×1440），缩放 100%
- 浏览器打开 `http://127.0.0.1:5173/`，F11 全屏
- Packet Tracer 打开 `pt\campus-final.pkt`，缩小放在副屏或画中画

### 2) 一键启动
```powershell
cd D:\zdsh\campus-twin
.\tools\demo_start.ps1
```
看到 5 项全 `[OK]` 再开始；`[WARN]` 说明 PT NC 没开，按提示处理。

### 3) 录屏工具
| 工具 | 说明 |
|---|---|
| **Windows Xbox Game Bar** | `Win+G` → 录制；免费、免装；默认录当前窗口/全屏 |
| **OBS Studio**（推荐） | 免费；可加"窗口采集"+ 摄像头画中画 + 麦克风；输出 mp4 |
| 剪辑 | 剪映（自动字幕）/ CapCut；加字幕与箭头标注 |

参数建议：1080p 30fps，码率 6–8 Mbps；录音用耳麦（环境噪音小）。

### 4) 台词技巧
- 别说"这里我做了 XX 功能"，说"**面试官最关心的数据真实性，我们这样保证**"
- 每个结论配一个动作：说"5 秒内出告警"的同时执行 shutdown
- 数字放慢说（5 秒、35 个场景、100%）

## 四、录制备注

1. **鼠标**：放慢、少抖动；每次点击前指向目标 1 秒再点。
2. **语速**：比平时慢 20%；关键数字重读一遍。
3. **节奏**：每 20–30 秒切一次画面（大屏/PT/AI 面板/终端），避免长时间静止。
4. **失败重录点**：如果 AI 回答超过 25 秒，剪辑时加速（加"×3 加速"角标）。
5. **字幕**：用剪映自动字幕，重点句手动加粗；技术名词（LangGraph、interrupt、flow-analysis）加英文角标。
6. **封面**：大屏截图 + 标题「校园网络数字孪生运维平台 · 真实数据源 + LangGraph 多 Agent」。

## 五、翻车预案（录制前必须确认）

| 风险 | 预案 |
|---|---|
| PT 崩了 / NC 掉线 | 切后端 `DRIVER=simulator` 演示模式（界面标注仿真数据）；或直接放预录片段 |
| LLM 超时 / 余额不足 | 切 `LLM_PROVIDER=mock` 离线规则回答，功能演示不中断 |
| 网络断了 | 全本地跑，只有真实 LLM 需要外网；mock 模式完全离线 |
| 端口被占 | `.\tools\demo_stop.ps1` 后 `.\tools\demo_start.ps1 -Restart` |
| 大屏空白/未连接 | 刷新页面；确认 `demo_start` 五项全 OK；看 `logs/` 下日志 |
